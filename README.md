
Multiscale Simplicial Complex Entropy Analysis

Zabaleta-Ortega, Alvaro, Carrizales-Velazquez, Carlos, Obregón-Quintana, Bibiana,
Guzmán-Vargas, Lev

This Python code is the methodology described in the paper Multiscale simplicial
complex entropy analysis of heartbeat dynamics. The multiscale
simplicial complex approximate entropy (MS-SCAE) is used. We describe 3 representative examples

1 Example 1
A white noise of length N = 10K with mean µ = 0 and standard deviation
σ = 1 is generated. Then a coarse-graining series y_τ is calculated with parameters τ = 2. Then the SCAE0 and SCAE1 are
calculated and printed.

2 Example 2
Here, a white noise (with same characteristcs of Example 1) is generated and the MS-SCAE
is calculated. The result of this example is a the curve generated by the average of SCAE0(τ )
and SCAE1(τ ) with its error bar as the standard deviation of each SCAE0 and SCAE1. The return of this example is a (non-stylized)
graph.

3 Example 3
From Physionet www.physionet.org (last accesed date: 1 December 2024), we consider three
cases of study: 1 Healthy, 1 congestive heart failure "CHF"and 1 atrial fibrilation "AF". We
consider segments of lenght N = 10K in order to compare this example with the results showed in
Figure 2 of our paper. As in Example 2, the return of this example are two (non-stylized) graphs
which show the curves SCAE0(τ) and SCAE1(τ) obtained from each RR-interval series of each
patient.
